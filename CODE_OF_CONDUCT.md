# Code of conduct

This project is one extension and a small set of issues and pull requests. Treat the people there with ordinary courtesy.

## Expected

- Assume good faith.
- Critique the change, not the person.
- Stay on the subject of MCP Tool Xplorer.

## Not acceptable

- Insults, harassment, or personal attacks.
- Sexual attention directed at someone who does not want it.
- Publishing someone else's private information, including secrets from an MCP config.

## Reporting

Email [garrardkitchen@gmail.com](mailto:garrardkitchen@gmail.com). Describe what happened and where. Do not include secrets.

A report is read by the maintainer. The response may be a warning, a hidden comment, or a blocked participant. This is a personal project, so the maintainer makes that call.
